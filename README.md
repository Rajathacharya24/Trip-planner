Trip Planner

A simple travel booking web application with a static frontend and a Spring Boot backend.

Overview
- Frontend: static HTML/CSS pages located in the `frontend/` directory. These pages implement the UI for browsing packages, exploring destinations, booking flows, and authentication.
- Backend: Java Spring Boot application in the `backend/` directory. Provides REST APIs for packages, bookings, and user authentication.

Quick Start

1. Frontend (static files)
  - Open the pages directly in a browser from `frontend/`, or serve them with a static HTTP server, for example:

```bash
python3 -m http.server --directory frontend 8000
# then open http://localhost:8000
```

2. Backend (development)
  - From the `backend/` directory, build and run with Maven:

```bash
cd backend
mvn spring-boot:run
```

  - Default API base: `http://localhost:8082/api/` (used by the frontend). Adjust application properties if needed.

Repository layout

- `frontend/` — static site (HTML, CSS, copied frontend assets)
- `backend/` — Spring Boot app (`pom.xml`, `src/`)
- Images currently at repository root: `pexels-*.jpg` (referenced by the frontend). They can be moved into `frontend/images/` on request.

Developer notes
- The frontend expects authentication tokens and user data in `localStorage` (keys: `token`, `userRole`, `userName`).
- Booking and admin flows post to backend endpoints; ensure the backend is running when testing interactive features.
- Build artifacts (`backend/target/`) were removed to keep the repo clean; they can be regenerated by building the backend.
